### 🔭 What I work on

- **ETL & data pipelines** — Dagster-orchestrated pipelines processing large multi-sheet Excel datasets (Malaysian parliamentary/state constituency data) into structured PostgreSQL silver/gold layers.
- **LLM-assisted data engineering** — using local LLMs (Ollama, Qwen, DeepSeek, Gemma) for semantic metadata generation, with deterministic code handling structural logic.
- **Geospatial analysis** — GeoPandas + satellite imagery (Sentinel-2 via CDSE OpenEO) for land use and regional analysis.
- **BI & reporting** — Power BI dashboards with DAX, gold-layer PostgreSQL models, and Excel-based reporting engines built on `xlwings`.
- **Full-stack dashboards** — React front-ends for data visualization and transparency tools.
